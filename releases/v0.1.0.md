# PDF Splitter v0.1.0

첫 공개 배포입니다.

## 포함 내용

- Windows 실행 파일
- PDFBox 3.0.7 썸네일 렌더러 자산
- 사용 문서
- Apache License 2.0, NOTICE, 써드파티 고지 파일

## 주요 기능

- 실제 PDF 페이지 썸네일 미리보기
- 리스트형 / 격자형 보기
- 페이지 확대 보기
- 페이지 사이 구분선 클릭 기반 분할
- 빠른 분할 단위 토글 및 숫자 입력
- 분할 완료 후 저장 위치 열기
- 시스템 / 라이트 / 다크 테마

## 보안

- 입력 경로 및 파일 시그니처 검증
- 대용량 / 과다 페이지 PDF 제한
- 암호화 PDF 차단
- 첨부파일, 자동 실행, JavaScript, 외부 실행 등 위험 기능 차단
- 분할 저장 시 임시 파일 후 확정
- 썸네일 렌더링 타임아웃 및 캐시 정리

## 참고

- 이 릴리즈는 `Apache License 2.0`으로 공개됩니다.
- 현재 릴리즈 패키지는 Windows 기준입니다.
- macOS 배포 산출물은 macOS 환경에서 별도 빌드 및 검증이 필요합니다.
